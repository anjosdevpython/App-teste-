# Dados de exemplo (seed)

Este arquivo contém exemplos de registros para popular o PocketBase em ambiente local.

## Como usar

1. Crie o admin no PocketBase (`http://localhost:8090/_/`).
2. Crie as collections conforme `docs/collections.md`.
3. Importe manualmente os registros usando a interface do PocketBase, substituindo os placeholders `{{aluno_id}}` e `{{turma_id}}` pelos IDs criados.

Arquivo: `seed/sample_data.json`.
